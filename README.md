# 착한가격업소을 한 눈에!
> 2024 기준으로 작성된 부산시에 등재된 착한가격업소를 지도로 보기 편하게~

## 사용 스택
- HTML/CSS/Javascript
- JQuery
- Python

## 세부 사항
- 카카오맵 API 와 연동
    - 마커 속성을 커스텀해서 사용자 상호작용 구현
- 공공데이터 포털 오픈 API 연동
    - 2024 기준 데이터 부족 및 정확한 정보 부기재로 직접 데이터를 전처리
    - xls 파일 읽은 후 가격 정보 추가 및 주소 정보 전처리
- 주소 (구, 동 등 정보) 정보를 통해 부산시내로 필터링 기능 구현

## 개선할 점
- 배포하기
- 코드를 모듈로 분리
- 데이터 최신화하기
- 레이아웃 수정 및 디자인 개선
- 필터링 및 검색 기능 최적화
